Architecture

Sequential 4-Stage Multi-Model Pipeline

Instead of isolated single-task models, our framework chains specialized workers via structured XML token propagation: \( y = f_{vlm}(f_{seg}(f_{det}(f_{cls}(x)))) \)

W1

Classification ($f_{cls}$)

ResNet-50 / FastAI

Pathology screening & confidence estimation. Gated selective mode skips downstream stages on negative frames.

W2

Detection ($f_{det}$)

YOLOv8-s (128 FPS)

Single-stage bounding box localization of lesions, cell nuclei, or hippocampus ROI.

W3

Segmentation ($f_{seg}$)

SAM 2.1 Hiera + LoRA

Promptable pixel-level mask extraction ($r=8, \alpha=16$) fine-tuned with BCE + Dice loss.

W4

Reasoning ($f_{vlm}$)

Qwen3.5-0.8B-LoRA

Vision-language clinical report generation fine-tuned on HuggingFace PathVQA (flaviagiammarino/path-vqa) and VQA-RAD (flaviagiammarino/vqa-rad).
