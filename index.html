Method

Selective Execution via Structured Tokens

Instead of running all stages unconditionally, PolypFlow emits a gating token after each stage. Downstream stages are only activated when the token confidence exceeds a threshold — dramatically reducing compute on negative cases.

🔀

Workflow-Centric Architecture

Four specialized fast.ai models arranged in a conditional chain. Each model is trained independently then orchestrated at inference via a lightweight token-routing layer.

fast.aiResNet-50ResNet-34
🪙

Structured Token Protocol

After each stage, a compact token [CLS:polyp|DET:0.92|SEG:0.89|REP:—] is emitted. The VLM reads these tokens to generate grounded clinical reports without raw pixels.

Token RoutingEarly Exit
📉

Selective Execution Mode

If f_cls returns normal, detection and segmentation are entirely skipped — reducing average latency by 68% and GPU load by 30pp in mixed datasets.

Quick Start

Get Running in Minutes

All commands use the same main.py entrypoint. Switch datasets with a single flag. 

# 1. Clone the repository
git clone https://github.com/your-org/polypflow
cd polypflow

# 2. Create and activate environment (conda)
conda create -n polypflow python=3.10
conda activate polypflow

# 3. Install dependencies (NumPy 1.x required for compatibility)
pip install fastai torch torchvision pillow pandas
pip install "numpy<2.0.0"   # Critical: fixes DLL conflicts on Windows

# 4. Verify installation
python -c "import fastai; print(fastai.__version__)"

# 5. Generate synthetic data and train (no download needed)
python main.py --prepare-data
python main.py --train --epochs 20
# Download Kvasir-SEG (~44MB) — Windows PowerShell
Invoke-WebRequest -Uri "https://datasets.simula.no/downloads/kvasir-seg.zip" `
                  -OutFile "Kvasir-SEG.zip"
Expand-Archive -Path "Kvasir-SEG.zip" -DestinationPath "."

# OR on Linux/macOS
wget https://datasets.simula.no/downloads/kvasir-seg.zip
unzip kvasir-seg.zip

# Parse dataset → generates Kvasir-SEG/processed/dataset.csv
python main.py --dataset kvasir --data-path .\Kvasir-SEG --prepare-data

# Train all 3 models on Kvasir-SEG
python main.py --dataset kvasir --data-path .\Kvasir-SEG --train --epochs 20

# Evaluate
python main.py --dataset kvasir --data-path .\Kvasir-SEG --eval
# Download PolypGen — register at synapse.org first
pip install synapseclient
synapse get syn26376615 --recursive

# Parse all 6 clinical centers → generates PolypGen/processed/dataset.csv
# Center split: C1-C4=train, C5=val, C6=test
python main.py --dataset polypgen --data-path .\PolypGen --prepare-data

# Train on PolypGen (positive + negative samples)
python main.py --dataset polypgen --data-path .\PolypGen --train --epochs 20

# Evaluate on held-out Center C6
python main.py --dataset polypgen --data-path .\PolypGen --eval
# Run selective inference (skips seg/vlm if no polyp detected)
python main.py --predict path/to/frame.jpg --mode selective

# Run full pipeline (always executes all 4 stages)
python main.py --predict path/to/frame.jpg --mode full `
               --question "Is there a polyp in this frame?"
